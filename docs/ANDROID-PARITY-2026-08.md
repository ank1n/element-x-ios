# iOS → Android: разница функционала (срез 01.08.2026, iOS build 317)

Для Andy (STAND). Каталог последних функциональных изменений iOS-сборки, которые
нужно реализовать в Android. Серверные контракты общие — они здесь главное.
iOS-референсы — ветка `stmob-ns-blur` форка `ank1n/element-x-ios`.

## 0. БЛОКЕР: openid при OIDC-логине
Без него Айлок не работает вовсе (0/3 Android-сессий имеют openid — замер Molly).
- Добавить `openid` в scope авторизации (как веб: `matrix-js-sdk/src/oidc/authorize.ts:56`; iOS: `AuthenticationService.swift`, `additionalScopes: ["openid"]`, коммит `1c3d4d515`).
- Действует ТОЛЬКО на новые логины — после правки нужен полный перелогин.
- Задача уже у тебя от Molly (#ops 01.08); здесь для полноты.

## 1. Диск (STMOB-275) — самый большой блок
Экран «Диск» в Приложениях. База URL — домен сессии (homeserver), путь `/api/files`
одинаков во всём семействе sTalk. Авторизация — Matrix-токен.

### Контракты (все живые, проверены с iOS):
- `GET /api/files` — параметры: `filter` (documents|images|media), `q` (поиск), `before` (курсор=ts), `limit` (деф.100), `from`/`to` (мс), `room_id`, `folder`, `starred=1`.
  Запись: `{eventId?, roomId?, blobId?, sender, filename, mimetype, size, msgtype, category, mxcUrl, ts, isEncrypted, folderId(ЧИСЛО|null), starred, sharedWith:[userID]}`.
  Ответ: `{files:[...], nextBefore(ЧИСЛО)}`.
- `GET /api/files/stats` — счётчики `{all, documents, images, media}`.
- `GET /api/files/folders` — `{folders:[{id(ЧИСЛО), name, count, hasCover, sharedWith}]}`.
- `GET /api/files/shared-with-me` — `{files:[{owner, ownerDisplay, eventId?, blobId?, mxc, name, mimetype, size, permission(read|write), isDiskDoc, viaFolder, viaFolderName, needsKeys, ts(ДРОБНОЕ!), recipients:[{user, display, permission}]}]}`.
- `GET /api/files/blob/:id` — содержимое записей без mxcUrl.
- Правило содержимого: есть mxcUrl → тянуть из Matrix (шифрованные — только через таймлайн комнаты, сервер ключей не имеет); нет — блоб.

### Декодеры — ТЕРПИМЫЕ (уроки кровью):
- folderId/id папки приходят числом; nextBefore числом; ts в shared-with-me дробный (`1785590849703.323`);
- записи разбирать поштучно: одна непонятая не роняет страницу;
- страница без единого нового файла или с неизменным курсором = конец списка (защита от вечного лоадера).

### UI (референс — iOS `DiskScreen.swift`, коммиты `b6a0a5288`…`972234498`):
1. Иконки типов по РАСШИРЕНИЮ + подпись расширения на плитке (Word синий #2563EB, PDF красный #EF4444, Excel #059669, PPT #F59E0B, txt #64748B, архивы #B45309, аудио #6366F1, видео #EC4899, изображения #0DBD8B; фолбэк — категория сервера).
2. Список во всю ширину; имя ОДНОЙ строкой, длинное прокручивается ГОРИЗОНТАЛЬНЫМ ЖЕСТОМ по имени (не автоскролл — dp отверг), затухание только справа.
3. Мета-строка (вся индикация здесь): аватарка ОТПРАВИТЕЛЯ → размер → дата → 💬 имя чата (резолв по roomId клиентом, с кэшем) → звезда → замок (шифрованный) → аватарки получателей шаринга (до 3 + «+N»). Только аватарки, без имён.
4. Карточный режим: превью изображений (mxc thumbnail, только незашифрованные; scaledToFill в фикс-рамке).
5. Поиск: строка закреплена (не прячется), серверный `q` или докачка всех страниц.
6. Режим «по папкам» — переключатель в тулбаре, СПИСОК с секциями: «Папки», «Чаты» (каждый чат с файлами = строка с именем и счётчиком; содержимое — `room_id` фильтр), «Вне папок» (клиентский срез folderId=null). Тап — содержимое со строкой «назад».
7. «Доступно мне» — чип в фильтрах: владелец+recipients аватарками, пилюля права (Чтение/Правка), источник «из папки X» (viaFolderName), `needsKeys` — пометка «замок перечёркнут» и честный отказ при открытии («попросите владельца прислать файл в чат»). Расшаренные ТАКЖЕ подмешиваются в общий список «Все» по ts.
8. Действия на файле (long-press): Открыть; Переслать (для файлов С событием — форвард события; БЕЗ события — содержимым через пикер комнат, как из Share Extension); Поделиться (системный share sheet; у шифрованных пункта НЕТ); Найти в чате (только с событием).
9. Пагинация: `before`-курсор, подгрузка у хвоста.

### Карточка «поделился файлом» в чате (аналог StalkFileShareView):
спека вёрстки от Molly в #ops 31.07 (`FileShareBody.tsx`); iOS-нюансы: пилюля права не переносится, при многих аватарках мета в две строки, резерв под штамп времени.

## 2. Айлок (STMOB-274)
- Проба door-2 (`POST /api/ailock/v1/sessions` доступность) — плитка видна только там, где отвечает.
- Чат: WS-стриминг, история, вложения (галерея + Диск-пикер, `POST /conversations/{id}/attachments`, cap 10MiB, id → `{content, attachment_ids}`), agent_id НЕ слать.
- Диктовка: сырой WAV PCM 16кГц mono → `POST /api/recording/stt/dictate`, кап 60с, индикатор уровня микрофона.
- **Markdown-рендер ответов, ВКЛЮЧАЯ время стриминга** (dp): блочный разбор (###-заголовки, списки с исходной нумерацией, код-блоки, цитаты), формат виден по мере печати (iOS: `AilockMarkdownText`, коммиты `c609f54b6` + `819714aa3`).
- Файл от агента: карточка без кнопки скачивания, если ссылка ведёт на /uploads/.

## 3. Приложения
- Иконки из реестра: `iconUrl` в `/apps-api/apps` (не-web клиенты) на белой скруглённой подложке с тенью.
- Календарь: НЕ картинка — живая плитка-дата (день недели + число, градиент #0088BB→#2FA98C 120°), рисует клиент (`WidgetsListScreen.swift`, `7f921a859`+`012413ba5`).

## 4. Пуши (уроки NSE → применимо к FCM-обработке)
STMOB-277, корень найден: держите короткий таймаут сетевых запросов пуш-процесса
(iOS: 5с) — протухший keep-alive сокет после простоя молча съедает весь таймаут;
вторая попытка после короткого таймаута спасает пуш. Плюс:
- различать «не найдено» (ретрай→заглушка) от «вычищено/отфильтровано» (тихий дроп);
- заглушка обязана нести room_id/event_id (тап открывает чат) и сниматься при
  доставке настоящего контента; дедуп-отметку снимать при показе заглушки.

## 5. Звонки
- База: STMOB-47 (гайд `docs/ANDROID-CALL-IMPLEMENTATION-GUIDE.md`, отдельная сага).
- Уроки PiP iOS (STMOB-278), если появится аналог: состояние «отбой был» не должно переживать звонок; демонстрация экрана = видео; окно и при гудках ВИДЕОзвонка, но не в аудио (чёрный квадрат бесит dp).
