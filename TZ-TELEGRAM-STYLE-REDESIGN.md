# Техническое задание: Редизайн Element X iOS в стиле Telegram

**Версия:** 1.0
**Дата:** 05 февраля 2026
**Приоритет:** Высокий
**Референс:** Telegram iOS 2022-2024 (до Liquid Glass)

---

## 1. Обзор

### 1.1 Цель
Переработать интерфейс Element X iOS для соответствия UX-паттернам Telegram (классический дизайн до октября 2025).

### 1.2 Ключевые изменения
- Нижний Tab Bar с 5 вкладками
- Убрать верхний header с аватаром (перенести в Профиль)
- Поисковая строка внутри контента (не в navigation bar)
- Фильтры-табы сверху списка (горизонтальный скролл)
- Плоский дизайн без transparency/blur эффектов

### 1.3 Структура Tab Bar

| # | Вкладка | Иконка | Описание |
|---|---------|--------|----------|
| 1 | Контакты | `person.2` | Список контактов |
| 2 | Звонки | `phone` | История звонков + записи |
| 3 | Чаты | `bubble.left.and.bubble.right` | Список комнат и DM |
| 4 | Приложения | `square.grid.2x2` | Виджеты и приложения |
| 5 | Профиль | `person.circle` | Настройки + профиль |

### 2.4 Компонент Filter Tabs (общий)

**Визуал:**
```
┌──────────────────────────────────────────────────────────────┐
│  Все    Непрочитанные    Личные    Группы    Каналы    →    │
│  ───                                                          │
│  ▲ подчеркивание активного                                    │
└──────────────────────────────────────────────────────────────┘
```

**Требования:**
- [ ] Горизонтальный ScrollView
- [ ] Padding: 16pt по бокам
- [ ] Spacing между табами: 24pt
- [ ] Активный таб: синий цвет + подчеркивание 2pt
- [ ] Неактивный: серый текст, без подчеркивания
- [ ] Анимация при переключении: 0.2s ease

**Код (референс):**
```swift
struct TelegramStyleFilterTabs: View {
    let tabs: [String]
    @Binding var selectedIndex: Int

    var body: some View {
        ScrollView(.horizontal, showsIndicators: false) {
            HStack(spacing: 24) {
                ForEach(tabs.indices, id: \.self) { index in
                    VStack(spacing: 8) {
                        Text(tabs[index])
                            .font(.system(size: 15, weight: .medium))
                            .foregroundColor(selectedIndex == index ? .blue : .gray)

                        Rectangle()
                            .fill(selectedIndex == index ? Color.blue : Color.clear)
                            .frame(height: 2)
                    }
                    .onTapGesture {
                        withAnimation(.easeInOut(duration: 0.2)) {
                            selectedIndex = index
                        }
                    }
                }
            }
            .padding(.horizontal, 16)
        }
    }
}
```

```swift
import Lottie

let animationView = LottieAnimationView(name: "TabContacts")
animationView.contentMode = .scaleAspectFit
animationView.loopMode = .playOnce

// Воспроизведение при выборе таба
func tabSelected() {
    animationView.play()
}

// Цвет иконки
animationView.setValueProvider(
    ColorValueProvider(UIColor.systemBlue.lottieColorValue),
    keypath: AnimationKeypath(keypath: "**.Fill 1.Color")
)
```

### 10.5 Поведение анимации
| Состояние | Действие |
|-----------|----------|
| Таб неактивен | Статичный первый кадр, серый цвет |
| Таб выбран | Воспроизведение анимации, синий цвет |
| Повторный тап на активный таб | Повторная анимация |
